Google Material Icons

Source: https://github.com/google/material-design-icons/tree/master/src
License: Apache 2.0, included in LICENSE.txt.

The original 24 px SVGs are unchanged. Resource names map to:

- back: navigation/arrow_back
- forward: navigation/arrow_forward
- home: action/home
- reload: navigation/refresh
- stop: navigation/close
- bookmark: action/bookmark_border
- folder: file/folder_open
- copy: content/content_copy
- browser: action/open_in_new

Qt SVG renders the icons locally. Their visible pixels are tinted with the
application palette, including a separate disabled state.
